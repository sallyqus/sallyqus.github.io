# Sisi Qu — Personal Website

A static personal website built with HTML, CSS, and JavaScript. No build step is required.

## Updating the site

- Edit `index.html` for page content and links.
- Edit `styles.css` for layout and appearance.
- Edit `app.js` for the mobile navigation.
- Update `assets/` for the CV and favicon; keep references in `index.html` in sync.

## GitHub Pages

In the repository’s **Settings → Pages**, choose **Deploy from a branch**, select **master**, and use the **/ (root)** folder. The intended site address is https://sallyqus.github.io/.

`.nojekyll` tells GitHub Pages to serve these static files directly.

The former homepage is preserved in `previous-homepage.html`. Existing posts under `2019/` and the `archives/` directory remain available.
